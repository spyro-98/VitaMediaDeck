# VitaMediaDeck icon candidates

The original five concepts explored VitaMediaDeck's earlier Midnight Halo
palette. The Signal / Shell redesign adds two theme-specific iterations:

1. `01-wave-ribbon.png` — playback ribbon and media wave
2. `02-media-deck.png` — stacked media cards and play cutout
3. `03-media-portal.png` — circular playback portal
4. `04-network-stream.png` — local/network streams converging into playback
5. `05-waveform-screen.png` — audio waveform resolving into video playback
6. `06-signal-shell.png` — dimensional segmented shell and telemetry aperture
7. `07-signal-shell-flat.png` — selected flat shell, play core, and cold machine telemetry

Each numbered PNG is a PS Vita-ready 128x128 indexed PNG. The `masters/`
directory contains the original first-round artwork; the two Signal / Shell
masters live in `assets/branding/`. Candidate 7 is active at
`sce_sys/icon0.png` and is mirrored to the three legacy branding filenames.

`comparison.png` shows candidates 1–3 across the top row and 4–5 across the bottom row.
