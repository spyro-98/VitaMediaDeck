# Scrollable L1 menus — 24 October 2026

The original all-theme scrolling design in this report is superseded by the
[fixed wheel/grid and vertical-list correction](home-dashboard-lto-2026-10-24.md).
Only Legacy, Deck 90 and Aperture now scroll; the remaining themes show all actions.
The original measurements below remain historical evidence.

App 1.4.1 / Vita APP_VER 01.05 follow-up. Test build `l1scroll-1024`, bubble
`VMD l1scroll-1024`, log `ux0:data/VitaMediaDeck/session_l1scroll-1024.txt`.
Includes the preceding Jellyfin provider and podcast-resume corrections.

## Layout and controls

Every theme has a bounded vertical viewport with a fixed title and footer.
Targets are no longer compressed to fit all ten sections plus Player/Download.
Groups retain additional spacing; the content order still places Jellyfin
immediately before Navidrome. Offscreen entries are culled from drawing and
cannot receive a touch through the fixed header or footer.

| Theme | Structure | Target height / row step |
| --- | --- | --- |
| Legacy | Grouped side drawer | 42 / 56 px, plus category gaps |
| Ghost Mesh | Orbital content and a separate application column | 64 px content, 84 px tools |
| Deck 90 | Terminal rail | 48 / 64 px |
| Signal | Content grid and application column | 76 / 100 px |
| Aperture | Film-strip rail | 52 / 72 px |
| Relay | Connected two-column path | 72 / 98 px |
| Mosaic | Three-column gallery, separate application row | 104 / 132 px |

Up/down or the left stick selects immediately and moves the viewport to keep
the target's border visible. Opening L1 starts around the active section.
Left/right retains spatial navigation or the audio Sections/Player page switch.
Dragging follows the finger, clamps at both ends and stops on release; a drag
never turns into activation. Footer arrows move through the viewport. Cross
opens, Circle/L1 closes. A scrollbar indicates the current position.

A critically damped camera follows the existing per-theme motion profile and
retargets continuously during rapid direction changes. One rounded offset is
shared by card faces, text and hitboxes; fixed clipping protects the title and
footer. Item entrances do not replay. Reduced motion snaps to the target.
Live Player/Download availability changes preserve the focused section by ID,
with bounded reanchoring instead of selecting an unrelated row. Theme changes
and suspend/clock discontinuities reset/clamp motion safely. The audio layout
page retains its independent three choices and does not inherit scroll gestures.

The scroll state is a few fields on each sidebar, reuses the existing spring
math and fonts, and creates no worker, file writes, textures or network jobs.
Only intersecting targets are drawn. This describes bounded implementation
cost, not measured Vita frame time or battery consumption.

## Verification and device acceptance

The host fixtures exercise all seven themes, IT/EN, each independent live-task
combination and normal/reduced motion. Checks cover complete navigation, held
repeat, rapid reversals, roomy/non-overlapping targets, drag release, footer
arrows, clipping, touch during panel movement, live-task focus and audio-page
isolation. Shared chrome, provider flows, page transitions and settings/guide
regressions are also run. Reference PNGs show top/middle/bottom of every menu.
Native Release/LTO and VPK integrity remain separate from console acceptance.

On Vita:

1. In each theme, open L1 and traverse every entry in both directions. Hold the
   d-pad/stick and reverse quickly; check legibility, focus borders and motion.
2. Drag up/down, release, tap a visible entry and use footer arrows. The menu
   must stop cleanly and never activate a clipped row behind its title/footer.
3. Repeat with Player and Download active. Let a task finish while navigating;
   the focused provider should remain selected. Check Jellyfin/Navidrome order.
4. From audio playback, switch Sections/Player and change artwork layout. Return
   to Sections, then reopen L1 from settings, providers, files and video playback.
5. Test reduced motion and suspend/resume. Verify real touch/GPU smoothness,
   readable spacing, unchanged playback and no per-item flicker.
