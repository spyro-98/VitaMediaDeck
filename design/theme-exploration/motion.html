Motion rules & performance gates ↗

Active is not focused

In Crossfade, the mint underline identifies the current tab. Only the amber moving surface owns input focus. When you enter the grid, the tab keeps its small context underline, not a second focus rectangle. Menus take ownership; closing one restores the previous position.

Animation never queues input

Rapid input retargets the same focus surface. There is no “finish animation before accepting the next key” gate. Particles are an eight-dot, finite experiment, off by default. This browser draft does not establish native frame time, GPU cost, or playback concurrency.
